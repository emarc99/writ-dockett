Freeze a wallet only when a real court order says so, and only for as long as it says so.

Writ checks a court order against the federal docket, reads it with Gemini, and has a Chainlink network write a signed attestation that freezes exactly the wallets the court named. When the order ends, the freeze ends.

How it works

1

Submit

The issuer uploads the order. Only the PDF's SHA-1 leaves the browser, in a request signed by the issuer's key.

2

Verify on the docket

Ten Chainlink nodes each fetch the docket from CourtListener: the case, the entry, that it is an order, and the court's own PDF hash.

3

Read, then decide in code

Gemini reads the order's terms. Code freezes only wallets that appear verbatim in the court's text, and applies Rule 65(b)'s 14-day limit.

4

Signed on-chain, lifted on time

The nodes sign one report for the registry. A docket sweep lifts the freeze when the court dissolves the order or it expires.

Built to be trusted

The AI reads; it does not decide. A hallucinated wallet cannot be frozen: it is not in the court's text.
Fails safe. Anything missing or mismatched is rejected with machine-readable reasons, never partly applied.
Only the issuer can ask. CRE's gateway refuses requests not signed by the authorized key.
Humans stay in the loop. Overrides are possible and every one is logged on-chain with a note.

Verify a court order

The PDF never leaves your browser: only its SHA-1 is sent. Chainlink CRE checks it against the court's copy on the federal docket (CourtListener / RECAP).

Docket sweep

					
Freezes have to end too. The sweep re-reads every active order's docket and lifts the freeze when the law says it ends.

				

			

			

				

					
What ends a freeze

					
    
						
  • DissolvedA later order ends it, e.g. denying the preliminary injunction.
    • 
						
  • SupersededA later order replaces it, e.g. a preliminary injunction.
    • 
						
  • ExtendedThe court extends it; the new end date is recorded.
    • 
						
  • ExpiredAn ex parte TRO reaches 14 days (Fed. R. Civ. P. 65(b)(2)).
